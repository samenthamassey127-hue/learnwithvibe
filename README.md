# VibeLearn NextGen 🧠⚡

An adaptive AI engagement studio engineered for **The Personalized Engagement & Learning Innovation Challenge** (`varcha.pdf`).

Powered 100% on-device by **Ollama (`llama3.2:1b`)** with **Zero Cloud Latency**, **Live Cognitive Fingerprinting**, **Predict-and-Reveal Sandbox Experiments**, and **Low-Connectivity Continuity Mode**.

---

## 🌟 The 3 Breakthrough Features

### 1. 🧠 Personal Learning Fingerprint
Instead of asking students how they learn through surveys, VibeLearn tracks **live behavioral response telemetry** across every interaction (Games vs Visuals vs Challenges vs Code).
- Continuously re-computes optimal modalities and difficulty gradients.
- Automatically adjusts Ollama's system prompt to match the student's current cognitive state.

### 2. 🧪 Interactive Experiment Sandbox (Active Discovery)
Replaces passive reading with a gamified **Predict → Run → Observe → Understand** cycle:
- Students inspect live Python code snippets and predict output before running them.
- Colour-coded runtime validation with Socratic curiosity follow-ups that update the learning fingerprint.

### 3. 📶 Low-Connectivity Continuity Mode
Addresses infrastructural and internet constraints:
- Operates offline with pre-cached curriculum and client-side simulation.
- Vault queue saves all offline activities locally and pushes them automatically upon reconnecting.

## 🚀 Quick Setup

### 1. Run Ollama Locally
```bash
ollama serve
# Ensure you have the lightweight 1B model:
ollama pull llama3.2:1b
```

### 2. Install & Launch VibeLearn
```bash
git clone https://github.com/samenthamassey127-hue/learnwithvibe
cd learnwithvibe
npm install
npm run dev
```

Visit: **http://localhost:3000**
